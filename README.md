# Эспресс — лендинг кондитерской и кулинарии

Готовый одностраничный сайт для небольшого кулинарного бизнеса: домашняя выпечка, торты, круассаны, хлеб и свежие салаты с доставкой.

Проект сделан по принципу **Mobile-First**: сначала продуман телефон, затем планшет и десктоп. Сборка не нужна — это обычные HTML, CSS и JavaScript.

## Что уже есть

- адаптивная шапка с логотипом, звонком и корзиной;
- главный экран с заголовком, преимуществами и CTA;
- каталог с тремя категориями и переключением без перезагрузки;
- карточки товаров с фото, описанием, весом, ценой и кнопкой «В корзину»;
- корзина: выезжает снизу на телефоне и справа на десктопе;
- изменение количества, удаление товаров, подсчёт итогов;
- бесплатная доставка от 2 500 ₽ и прогресс-бар;
- форма заказа: имя, телефон, адрес, наличные / перевод;
- формирование текста заказа и открытие WhatsApp или Telegram;
- сохранение корзины в `localStorage`;
- контакты, режим работы и соцсети в подвале;
- доступная разметка, управление с клавиатуры, фокус-ловушка в корзине;
- 100/100 по Accessibility, Best Practices и SEO в Lighthouse.

## Структура

```text
espresso-landing/
```

## 1. Запуск локально

Самый простой вариант — открыть `index.html` двойным кликом. Сайт сразу откроется в браузере.

Если нужен локальный сервер (удобнее для проверки корзины и шрифтов):

```bash
# из папки espresso-landing
python -m http.server 8000
```

Затем откройте в браузере:

```text
http://localhost:8000
```

Подойдёт и расширение **Live Server** в VS Code.

## 2. Настройка перед публикацией

### Телефон, WhatsApp и Telegram

Откройте `script.js` и измените блок `CONFIG` в самом начале:

```js
const CONFIG = {
  whatsappPhone: "79990000000",       // только цифры, без + и пробелов
  telegramUsername: "espress_owner",  // username без @
  deliveryPrice: 290,
  freeDeliveryFrom: 2500,
  storageKey: "espress-cart-v1"
};
```

Пример:

```js
whatsappPhone: "79001234567",
telegramUsername: "espress_shop"
```

Затем замените тестовый номер `+7 999 000-00-00` и ссылки на него в `index.html`:

- шапка;
- кнопка «Позвонить» на главном экране;
- блок меню;
- подвал;
- ссылки на WhatsApp, Telegram и VK в контактах.

### Как работает отправка заказа

При нажатии **«Оформить заказ»** сайт:

1. проверяет имя, телефон и адрес;
2. собирает товары, количество, сумму и данные доставки;
3. формирует готовый текст заказа;
4. открывает WhatsApp с уже заполненным сообщением.

Пользователю остаётся нажать «Отправить» в мессенджере. Это безопасный вариант без backend и без хранения персональных данных на сайте.

Кнопка **«Отправить заказ в Telegram»** делает то же самое через ссылку `t.me`. В некоторых клиентах Telegram текст может не подставиться автоматически — тогда его можно скопировать из сообщения WhatsApp или вставить вручную. Для полноценной автоматической отправки в Telegram понадобится бот и небольшой сервер.

### Товары и цены

Все товары лежат в массиве `products` в `script.js`. Чтобы добавить позицию, скопируйте объект:

```js
{
  id: "new-product",
  category: "cakes", // cakes | bakery | salads
  name: "Название",
  description: "Короткое описание",
  weight: "500 г",
  price: 590,
  badge: "Новинка", // можно оставить пустую строку
  image: "https://images.unsplash.com/...",
  alt: "Описание фото"
}
```

### Цвета и шрифты

Палитра собрана в `:root` в начале `styles.css`. Основные цвета:

- `--bg` — кремовый фон;
- `--coffee` — кофейный;
- `--olive` — мягкий оливковый;
- `--terracotta` — акцентный терракотовый.

Шрифты подключены из Google Fonts: **Playfair Display** для заголовков и **Manrope** для интерфейса.

### Фотографии

Сейчас используются фотографии с Unsplash по прямым ссылкам. Для реального бизнеса лучше заменить их на собственные фото: положите изображения в папку `images/` и укажите относительные пути, например `images/cake.jpg`. Так сайт будет выглядеть уникально и не зависеть от внешнего сервиса.

## 3. Бесплатная публикация

### Вариант A. GitHub Pages

1. Создайте аккаунт на [github.com](https://github.com), если его ещё нет.
2. Создайте новый публичный репозиторий, например `espresso-landing`.
3. Загрузите в корень репозитория файлы:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `favicon.svg`
   - при желании `README.md`
4. Откройте **Settings → Pages**.
5. В блоке **Build and deployment** выберите:
   - Source: **Deploy from a branch**;
   - Branch: **main**;
   - Folder: **/ (root)**.
6. Нажмите **Save** и подождите 1–2 минуты.
7. Сайт будет доступен по адресу:

```text
https://ВАШ_ЛОГИН.github.io/espresso-landing/
```

Важно: файл `index.html` должен лежать в корне репозитория, а имена файлов должны совпадать с теми, что указаны в ссылках (`styles.css`, `script.js`). GitHub Pages учитывает регистр букв.

### Вариант B. Netlify

1. Зарегистрируйтесь на [netlify.com](https://www.netlify.com/).
2. Нажмите **Add new site → Deploy manually**.
3. Перетащите папку `espresso-landing` целиком в окно загрузки.
4. Netlify сразу выдаст ссылку вида:

```text
https://random-name-123.netlify.app
```

5. В **Site settings → Domain management** можно изменить имя сайта или подключить свой домен.

Netlify также умеет автоматически обновлять сайт из GitHub: выберите **Import from Git**, укажите репозиторий, оставьте build command пустым, а publish directory — `/` или корень проекта.

### Вариант C. Cloudflare Pages

Подходит, если нужен ещё один бесплатный вариант:

1. Загрузите проект в GitHub.
2. В Cloudflare Pages создайте проект из репозитория.
3. Framework preset — **None**, build command — пустая, output directory — `/`.
4. Нажмите **Save and Deploy**.

## Технологии

- HTML5;

- чистый JavaScript (ES6+);
- Google Fonts;
