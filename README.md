# Эспресс — лендинг кондитерской и кулинарии

Готовый одностраничный сайт для небольшого кулинарного бизнеса: домашняя выпечка, торты, круассаны, хлеб и свежие салаты на вес с доставкой по Мирному.

Проект сделан по принципу **Mobile-First**: сначала продуман телефон, затем планшет и десктоп. Сборка не нужна — это обычные HTML, CSS и JavaScript.

## Что уже есть

- адаптивная шапка с логотипом, звонком и корзиной;
- главный экран с заголовком, преимуществами и CTA;
- каталог с тремя категориями и переключением без перезагрузки;
- обычные товары с фиксированной ценой и весовые — с ценой за 100 г и выбором граммовки;
- корзина: выезжает снизу на телефоне и справа на десктопе;
- изменение количества, удаление товаров, подсчёт итогов;
- бесплатная доставка от 2 500 ₽ и прогресс-бар;
- форма заказа: имя, телефон, адрес, оплата переводом или по QR-коду;
- отправка заказа в **MAX** (основной канал), WhatsApp или Telegram;
- QR-код для оплаты рисуется прямо на сайте, без внешних сервисов;
- сохранение корзины в `localStorage`;
- контакты, режим работы и соцсети в подвале;
- доступная разметка, управление с клавиатуры, фокус-ловушка в корзине.

## Структура

```text
espresso-landing/
├── index.html      # разметка страницы
├── styles.css      # все стили и адаптивность
├── script.js       # каталог, корзина, валидация, отправка заказа
├── qrcode.min.js   # генератор QR-кодов (библиотека qrcode-generator, MIT)
├── favicon.svg     # иконка сайта

└── README.md       # эта инструкция
```

## 1. Запуск локально

Самый простой вариант — открыть `index.html` двойным кликом. Сайт сразу откроется в браузере.

Если нужен локальный сервер (удобнее для проверки корзины и шрифтов):

```bash
# из папки espresso-landing
python -m http.server 8000
```

Затем откройте в браузере:

```text
http://localhost:8000
```

Подойдёт и расширение **Live Server** в VS Code.

## 2. Настройка перед публикацией

Все основные настройки собраны в блоке `CONFIG` в начале `script.js`:

```js
const CONFIG = {
  phone: "+79965822164",
  phoneDisplay: "+7 996 582-21-64",

  maxLink: "",
  whatsappPhone: "79965822164",
  telegramUsername: "espress_owner",

  paymentQrImage: "",
  paymentQrData: "",
  paymentQrDemo: true,

  deliveryPrice: 290,
  freeDeliveryFrom: 2500,
  storageKey: "espress-cart-v2"
};
```

### Телефон и адрес

Телефон меняется в двух местах:

1. `CONFIG.phone` и `CONFIG.phoneDisplay` в `script.js`;
2. ссылки `tel:+79965822164` в `index.html` — шапка, кнопка «Позвонить», блок меню, подвал.

Адрес указан в подвале `index.html` (блок «Контакты») и в ссылке на Яндекс.Карты.

### MAX, WhatsApp и Telegram

MAX открывается первым — это основной канал. **Ссылки по номеру телефона в MAX нет**: адрес вида `max.ru/79965822164` отвечает ошибкой 404. Работают только приглашения, их берут в приложении MAX:

- личный профиль: `https://max.ru/u/длинный-код` (Контакты → «+» → «Пригласить по ссылке»);
- группа или чат: `https://max.ru/join/код` (название группы → «Пригласить по ссылке»);
- публичный канал: `https://max.ru/ник`;
- бот для бизнеса: `https://max.ru/idИНН_bot`.

Впишите ссылку в `CONFIG.maxLink`. WhatsApp — только цифры в `whatsappPhone`, Telegram — ник без `@` в `telegramUsername`.

Пока `maxLink` пустой, кнопка MAX открывает мессенджер, а номер магазина показывается в подсказке: покупатель находит вас в MAX по номеру телефона. Как только появится ссылка-приглашение — вставьте её, и кнопка начнёт открывать чат напрямую.

MAX не поддерживает подстановку текста в чат, поэтому при оформлении заказа текст **копируется в буфер обмена**, а MAX открывается отдельно. Покупателю остаётся вставить сообщение и отправить. В WhatsApp и Telegram текст подставляется автоматически.

### Как работает отправка заказа

При нажатии **«Оформить заказ в MAX»** сайт:

1. проверяет имя, телефон и адрес;
2. собирает товары, вес, количество и сумму;
3. формирует готовый текст заказа и копирует его;
4. открывает чат с магазином в MAX.

Кнопки **WhatsApp** и **Telegram** под тем же блоком делают то же самое, но сразу с заполненным сообщением. Backend и хранение персональных данных на сайте не нужны.

### Оплата по QR-коду

В форме заказа два способа оплаты: переводом на карту и по QR-коду (СБП). При выборе QR на сайте рисуется код и показывается сумма заказа.

Два варианта настройки:

**Вариант 1 — картинка от банка (рекомендуется).** Скачайте QR в приложении банка, положите файл рядом с `index.html` и укажите имя:

```js
paymentQrImage: "qr-sbp.png",
paymentQrDemo: false
```

**Вариант 2 — ссылка СБП.** Сайт сам нарисует QR из строки:

```js
paymentQrData: "https://qr.nspk.ru/AS10000...",
paymentQrDemo: false
```

В `paymentQrData` можно использовать `{amount}` — подставится итоговая сумма заказа.

Пока `paymentQrDemo: true`, в панели видна подсказка «Демо-режим». После установки настоящего QR переключите флаг на `false` — подсказка исчезнет.

### Товары и цены

Все товары лежат в массиве `products` в `script.js`.

Обычный товар с фиксированной ценой:

```js
{
  id: "new-product",
  category: "cakes", // cakes | bakery | salads
  name: "Название",
  description: "Короткое описание",
  weight: "500 г",
  price: 590,
  badge: "Новинка", // можно оставить пустую строку
  image: "https://images.unsplash.com/...",
  alt: "Описание фото"
}
```

Весовой товар — цена за 100 г и границы граммовки:

```js
{
  id: "new-salad",
  category: "salads",
  name: "Название салата",
  description: "Короткое описание",
  unit: "weight",
  pricePer100g: 140,   // цена за 100 грамм
  minWeight: 100,      // минимальный заказ, г
  maxWeight: 2000,     // максимум, г
  weightStep: 50,      // шаг кнопок «−» и «+», г
  defaultWeight: 250,  // вес по умолчанию
  badge: "",
  image: "https://images.unsplash.com/...",
  alt: "Описание фото"
}
```

Стоимость весовой позиции считается автоматически: `цена за 100 г × вес / 100`. Одинаковые товары с разным весом попадают в корзину отдельными строками.

### Цвета и шрифты

Палитра собрана в `:root` в начале `styles.css`. Основные цвета:

- `--bg` — кремовый фон;
- `--coffee` — кофейный;
- `--olive` — мягкий оливковый;
- `--terracotta` — акцентный терракотовый.

Шрифты подключены из Google Fonts: **Playfair Display** для заголовков и **Manrope** для интерфейса.

### Фотографии

Все фотографии уже лежат в папке `images/` в формате WebP и подключены относительными путями (`images/chocolate-cake.webp`). Сайт не зависит от внешних фотосервисов и загружается быстро.

Чтобы заменить фото на своё:

1. Подготовьте картинку шириной 900–1200 px.
2. Сохраните её в `images/` под новым именем, например `images/my-cake.webp` (подойдёт и `.jpg`).
3. Укажите путь в массиве `products` в `script.js` и в `index.html` (главный экран и блок «О нас»).

## 3. Бесплатная публикация

### Вариант A. GitHub Pages

1. Создайте аккаунт на [github.com](https://github.com), если его ещё нет.
2. Создайте новый публичный репозиторий, например `espresso-landing`.
3. Загрузите в корень репозитория файлы:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `qrcode.min.js`
   - `favicon.svg`
   - папку `images/` целиком
   - при желании `README.md`
4. Откройте **Settings → Pages**.
5. В блоке **Build and deployment** выберите:
   - Source: **Deploy from a branch**;
   - Branch: **main**;
   - Folder: **/ (root)**.
6. Нажмите **Save** и подождите 1–2 минуты.
7. Сайт будет доступен по адресу:

```text
https://ВАШ_ЛОГИН.github.io/espresso-landing/
```

Важно: файл `index.html` должен лежать в корне репозитория, а имена файлов должны совпадать с теми, что указаны в ссылках (`styles.css`, `script.js`, `qrcode.min.js`). GitHub Pages учитывает регистр букв.

### Вариант B. Netlify

1. Зарегистрируйтесь на [netlify.com](https://www.netlify.com/).
2. Нажмите **Add new site → Deploy manually**.
3. Перетащите папку `espresso-landing` целиком в окно загрузки.
4. Netlify сразу выдаст ссылку вида:

```text
https://random-name-123.netlify.app
```

5. В **Site settings → Domain management** можно изменить имя сайта или подключить свой домен.

Netlify также умеет автоматически обновлять сайт из GitHub: выберите **Import from Git**, укажите репозиторий, оставьте build command пустым, а publish directory — `/` или корень проекта.

### Вариант C. Cloudflare Pages

1. Загрузите проект в GitHub.
2. В Cloudflare Pages создайте проект из репозитория.
3. Framework preset — **None**, build command — пустая, output directory — `/`.
4. Нажмите **Save and Deploy**.

## 4. Что проверить перед запуском

- [ ] телефон и адрес заменены в `script.js` и `index.html`;
- [ ] в `CONFIG.maxLink` вставлена ссылка-приглашение из MAX (`max.ru/u/...` или `max.ru/join/...`);
- [ ] заменены WhatsApp и Telegram;
- [ ] установлен настоящий QR для оплаты, `paymentQrDemo` выключен;
- [ ] проверены цены за 100 г и шаг граммовки у весовых товаров;
- [ ] обновлены часы работы и соцсети;
- [ ] фотографии соответствуют товарам;
- [ ] протестирован заказ с телефона: вес, корзина, форма, QR, MAX;
- [ ] проверена ссылка на сайт после публикации.

## Технологии

- HTML5;
- CSS3 (Grid, Flexbox, `clamp()`, `dvh`, CSS-переменные);
- чистый JavaScript (ES6+);
- qrcode-generator (MIT) для QR-кодов;
- Google Fonts;
- фотографии Unsplash сохранены локально в `images/` (WebP).

Без фреймворков, сборщиков и платных зависимостей — сайт можно загрузить на любой статический хостинг.
